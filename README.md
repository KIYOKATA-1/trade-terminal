# Trade Terminal

Учебный терминал для виртуальной торговли на Next.js и TypeScript.

Установка зависимостей и запуск в режиме разработки:

```bash
pnpm install
pnpm dev
```

Приложение доступно по адресу http://localhost:3000.

Проверка кода и production-сборка:

```bash
pnpm lint
pnpm build
```

Запуск собранного приложения:

```bash
pnpm start
```
